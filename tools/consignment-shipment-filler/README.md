# 유상사급 일별 출고수량 채우기

원본(Sheet1)의 출고수량(I열)을 [인도처 + 자재(품번) + 출고일] 기준으로
합산해서, 입력 템플릿("유상사급" 시트)의 일자 칸(N열=01일 ~ AR열=31일)에
채워 넣는 자동화 프로그램입니다. 파이썬 표준 라이브러리만 사용하므로
별도 설치 없이 바로 실행됩니다(Python 3.7+).

파일 4개로 구성됩니다.

| 파일 | 용도 |
|---|---|
| `fill_daily_shipment.py` | 핵심 로직 (다른 세 파일이 이걸 불러다 씁니다) |
| `gui.pyw` | **화면(창) 버전** — 파일 선택 창에서 클릭만으로 실행 |
| `실행.bat` | Windows에서 `gui.pyw`를 더블클릭처럼 켜주는 실행기 |
| `exe로_만들기.bat` | 이 PC에서 딱 한 번 실행하면 진짜 `.exe` 실행파일을 만들어줍니다 |

## 매달 쓰는 방법 (가장 쉬움 — 화면 버전)

1. 이 폴더의 **`실행.bat`을 더블클릭**합니다. (파이썬이 미리 설치되어 있어야 합니다 — 없다면 python.org에서 설치, 설치 시 "Add python.exe to PATH" 체크)
2. 창이 뜨면 **① 템플릿 파일**(유상사급 시트가 든 xlsx)을 "찾아보기"로 선택합니다.
3. 원본(Sheet1)이 같은 파일 안에 있으면 체크박스를 켜고, 별도 파일이면 **② 원본 파일**을 선택합니다.
4. **실행** 버튼을 누르면 잠시 후 결과 요약이 뜨고, 원본 파일명 뒤에 `_filled`가 붙은 결과 xlsx가 같은 폴더에 저장됩니다.
5. "결과 파일이 있는 폴더 열기" 버튼으로 바로 확인할 수 있습니다.

## 진짜 실행파일(.exe)로 만들기 (한 번만 하면 됨)

인터넷이 되는 Windows PC에서 **`exe로_만들기.bat`을 딱 한 번 더블클릭**하세요.
자동으로 필요한 도구(PyInstaller)를 설치하고 `dist\유상사급자동화.exe`를
만들어 줍니다. 이후로는 그 `.exe` 파일 하나만 복사해서 옮겨 써도
파이썬 설치 없이 바로 실행됩니다. (지금 이 대화 세션은 인터넷이 막혀있어
직접 exe를 만들어 드릴 수 없어서, 이 배치 파일로 사용자 PC에서 한 번에
만들도록 준비했습니다.)

## 명령줄(터미널)로 쓰는 방법

Sheet1과 유상사급 시트가 한 파일에 같이 있는 경우:

```bash
python3 fill_daily_shipment.py 템플릿.xlsx
```

원본과 템플릿이 서로 다른 파일인 경우:

```bash
python3 fill_daily_shipment.py 템플릿.xlsx --source 원본.xlsx
```

결과는 기본적으로 템플릿 파일명 뒤에 `_filled`를 붙여 저장됩니다.
저장 경로를 직접 지정하려면 `--output 결과.xlsx`를 추가하세요.

시트 이름이 다르면 `--src-sheet`, `--dst-sheet`로 지정할 수 있습니다.

## 동작 규칙

- 원본에서 **출고일이 실제 날짜인 행만** 집계합니다. 소계/합계/머리글처럼
  날짜가 없는 행은 전부 제외됩니다.
- 인도처·자재는 **텍스트로 비교**합니다(앞뒤 공백 제거). 숫자로 저장된
  품번(`12345.0`)과 문자 품번(`"12345"`)은 같은 값으로 매칭됩니다.
- 같은 (인도처+자재+같은 날짜)가 여러 건이면 출고수량을 **합산**합니다.
- 템플릿에서 인도처·자재가 모두 있는 데이터 행만 채우며, 매칭된 날짜는
  합산값, 매칭이 없는 날짜는 **0**으로 채웁니다.
- 일자 칸(N~AR) 외의 셀·서식·기존 수식(AT/AU/AV 등 합계열)은 전혀
  건드리지 않습니다.

## 실행 결과 확인

실행하면 콘솔에 사용/제외 행 수, 매칭된 셀 수, 원본 총 출고수량과 템플릿에
기입된 수량 합계가 출력됩니다. 두 총량이 일치하면 `✓ 원본 총량과 템플릿
기입 총량 일치`가 표시됩니다. 불일치하면 템플릿에 해당 (인도처+자재) 행이
빠져 있다는 뜻이므로, 함께 출력되는 미매칭 원본키 목록을 참고해 템플릿에
품번 행을 추가하세요.

## 원본/템플릿 열 위치 (고정, 다르면 스크립트 상단 상수 수정)

- **원본 Sheet1**: 인도처=B, 출고일=C, 자재(품번)=E, 출고수량=I
- **템플릿 유상사급**: 인도처=C, 자재=E, 일자 칸 N열(01일)~AR열(31일)
